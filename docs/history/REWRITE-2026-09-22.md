# History rewrite, 2026-09-22

On 2026-09-22 the repository's history was rewritten once, with `git filter-repo --path training/ --invert-paths`,
to drop 59 model checkpoints (312 MB, `training/railml_ane_ckpts_v6/ckpt_*.bin`) committed on 2026-04-05 and
gitignored since. Nothing else changed: every rewritten commit has the same tree as its original except for the
absence of `training/`, so the seed binary, the compiler and every attested file at a mapped commit are
byte-identical to what the attestation named.

`commit-map-2026-09-22.txt` maps every old commit id to its new one (`old new`, one per line). To follow an
attestation or a note that names an old id:

    grep '^<old id>' docs/history/commit-map-2026-09-22.txt

The pre-rewrite refs and objects are held offline (a mirror and a bundle on the Mini and the Studio).
