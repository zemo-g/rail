## Dependency boundary

The seed binary has **no C**: the GC and runtime are ARM64 assembly embedded in the
compiler, and since v5.2.0 it assembles, links, and code-signs itself (no `as` / `ld` /
`codesign`). Optional concurrency, GPU (Metal), and JIT features use a small
asm/ObjC/C boundary - 31 in-tree non-Rail files, each named in [`SHIMS.md`](../SHIMS.md).

## Known accepted-but-crashing idioms

Compilation proves a program is *accepted by the binary you run*, not that it is
*correct*. These compile today but can crash at runtime - do not rely on them
(tracked for compile-time rejection):

- inline lambdas passed to `filter` / `fold` (use named predicate functions)
- `&&` / `||` do not short-circuit - both sides always evaluate
- `split` is single-character (use `str_split` for multi-char delimiters)
