## Findings

- **Apple's bundled jsc is a CI-grade WASM verifier**. Same engine as Safari WebKit; passing under jsc is strong evidence of in-browser compatibility. Path: `/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc`. Has `WebAssembly`, `readFile(path, "binary")`, `print`, `quit`. Don't try `pip3 install wasmtime` on macOS — Apple's hardened-runtime Python is killed by EXC_GUARD when wasmtime tries to install its trap handler.
- **Rail WASM float-param typing**. The emitter only marks function params as float when a Rail-side caller passes a float to that position. JS-only callers leave params untyped → register-recursive accumulators get garbled. Workaround everywhere: thread accumulators / dt / etc. through 1-cell `float_arr`s. `ke_acc_loop` was the original carrier of this pattern; LIC and particle_step now use it too.
- **`/witness.html` doesn't collide with the `/witness/*` Worker namespace**. Path-segment matching means top-level `*.html` pages ship safely alongside Worker-routed prefixes. No Worker patch needed.
- **`./deploy.sh` cache-busts via the `?v=<hash>` query string** appended to `_shared/site.{css,js}` references at upload time. Pages NOT redeployed keep the OLD hash baked in, so a CSS-only change still requires re-deploying every HTML page that references it. Always use `./deploy.sh` (no args = full sweep) for shared-asset changes.
- **Cloudflare cache purge in deploy.sh is best-effort**. If the CF_TOKEN lacks `Zone:Cache:Purge`, the upload succeeds but the CDN edge serves stale HTML for minutes-to-hours. Verify with `?reload=$RANDOM` query.
- **Mini holds its own CF_TOKEN copy** (in addition to Studio's `~/Desktop/rings`). Future remote deploys initiated from Mini don't need to SSH back to Studio for the token. SSH alias `studio` reaches Studio over Tailscale.
